# 포메이션 메이커 (Formation Maker)

축구 선발 라인업을 만드는 웹 앱. 포메이션을 고르고, 각 자리에 선수 사진을 넣어
나만의 스쿼드 카드를 만든다.

- 9종 포메이션 (4-3-3 · 4-4-2 · 4-2-3-1 · 3-5-2 등)
- 자리별 사진 카드 (색상 테마 6종, 확대·위치 조정)
- 자리 바꾸기 / 카드 복사 / 교체 명단
- 브라우저에 자동 저장 (오프라인 사용 가능)

단일 정적 HTML 앱입니다. `index.html` 하나로 동작합니다.

## 로컬에서 보기

```bash
npx serve .
# 또는 index.html 을 브라우저로 열기
```

## 배포

정적 사이트로 Vercel에 배포됩니다. 별도 빌드 과정이 없습니다.
